# v1.48 — Canonical Hypothesis Synchronization

CYDRA now uses one canonical `HypothesisState` enum from the persistent hypothesis domain. Planner hypotheses explicitly carry that state while retaining planner-specific probability and prediction data.

The planning/persistent boundary is implemented by `cydra.hypothesis_bridge`:

- canonical identity is `hypothesis:<planner name>`;
- planner probability maps to persistent belief;
- hypothesis state crosses the boundary explicitly;
- declared predictions are preserved as explicitly tagged planning metadata;
- rehydration never invents predictions;
- immutable conversion does not mutate its source;
- contradiction detection consumes the canonical hypothesis state model;
- belief updates preserve explicit hypothesis state.

The boundary remains explicit: planning data is not inferred from invariant confidence, and missing information remains missing.
