# v1.49 — Auditable Belief-State Persistence

Belief updates are now persisted as explicit transitions in the canonical reasoning graph.

Each transition retains:

- canonical hypothesis identity;
- prior and posterior probability;
- prior and posterior semantic state;
- the observation that caused the transition;
- optional evidence and causal-chain links;
- update status and rationale.

Evidence polarity is conservative. A supported hypothesis receives an explicit `supports` edge, a contradicted hypothesis receives `contradicts`, and an unresolved hypothesis receives neither. Probability ranking is not treated as proof and is not converted into semantic state.
